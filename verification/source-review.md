# 소스 보안 검토 기록

검토일: 2026-10-18. 대상: 0.8.0 공개 소스와 0.8.1 수정 소스. **AI 지원 소스 검토와 기능 회귀 검사이며 전문 기관의 독립 침투 시험·보안 인증이 아닙니다.** 최종 APK의 해시·권한·빌드 비교 결과는 [버전별 자료](README.md)를 따릅니다.

## 발견 사항과 수정 범위

| 항목 | 0.8.0에서 확인한 경로 | 0.8.1 수정 |
|---|---|---|
| 알림 동의 보존 | 기존 푸시 연결 상태로 자동 등록을 켜는 migration이 ‘나중에’를 덮어쓸 수 있음 | 명시적인 보류·끄기를 유지하고, 공개 URL 확인 기능은 앱의 동의 안내를 거쳐 켬 |
| 자동 외부 전환 | 원본 페이지의 자동 최상위 외부 이동도 Android 외부 열기로 전달될 수 있음 | 웹 자동 이동과 사용자 링크 클릭을 구분해 자동 외부 앱 열기를 제한 |
| 불필요한 캡처 권한 | 독립 촬영·녹음 기능 없이 일반 WebView 카메라·마이크 승인 경로가 남아 있음 | 카메라·마이크 권한과 승인 경로 제거. 사진 선택·편집·첨부·저장은 유지 |
| 이미지 저장 자원 제한 | 이미지 서버가 계속 바이트를 보내면 파일 크기·전체 전송 시간 상한이 없었음 | 이미지 한 장 100MiB, 저장 전송 120초 제한. 초과 시 이번 작업이 만든 새 파일·항목만 정리 |

수정 완료 여부는 해당 버전의 검사 결과와 소스를 함께 확인해야 합니다. 버그 발견은 악성코드나 의도적인 백도어를 발견했다는 뜻이 아닙니다. 과거 버전에서 이미 전송된 자료가 새 앱 설치만으로 소급 삭제된다는 의미도 아닙니다. 알림을 끄면 서버 정리를 요청하는 경로를 제공합니다.

수정 후 Android JVM 회귀 검사 **747회 통과, 실패·오류·스킵 0**, Android lint 오류 0을 확인했습니다. 해시·서명·권한·재현 비교·업로드 보고서 검증 도구에 대한 별도 합성 입력 검사도 **44회 통과**했습니다. 테스트 코드·실제 게시글·기기 정보·개인 로그는 공개하지 않습니다. 이 개수는 개발 검증 기록이며 백신 검사 수나 외부 감사 인증이 아닙니다.

동의 수정은 현재 꺼짐·보류 선택을 보존합니다. 이전 버전이 이미 켜 놓은 값과 사용자가 직접 켠 값을 현재 설정만으로 완전히 구분할 수 없어, 기존 켜짐을 일괄 소급 원복하지는 않습니다.

## 확인한 보호 장치

- APK는 릴리스 서명을 사용하며 디버깅을 끕니다. 개인키는 APK와 저장소에 포함하지 않습니다.
- 네이티브 메시지 수신은 지정된 HTTPS 원본·최상위 프레임과 현재 화면 상태를 확인하고, 지원하는 작업의 입력을 제한합니다. 임의 셸 명령·파일 경로·원격 코드를 실행하는 범용 브리지는 제공하지 않습니다.
- 파일 선택은 시스템 선택기에서 지정한 자료를 사용합니다. 이미지 저장은 새 MediaStore 항목 또는 이 작업이 만든 새 파일을 사용하며, 기존 사진을 덮어쓰는 경로를 피합니다.
- 다운로드의 HTTPS 리다이렉트와 쿠키 전달 범위를 제한합니다. 외부 이미지 서버에 디시 로그인 쿠키를 무조건 전달하지 않습니다.
- 푸시 설치 인증·등록 증명·공개 URL 형식·구독 만료·대기 작업을 확인합니다. 서버는 비밀번호·브라우저 로그인 쿠키 없이 공개 댓글을 읽습니다.
- 정적 검색 범위에서 연락처·문자·위치 탈취, 접근성 원격 제어, 셸 명령 실행, 원격 DEX를 내려받아 실행하는 자체 경로는 발견하지 못했습니다. 이 문장은 모든 라이브러리와 모든 조건부 실행의 부재를 증명하지 않습니다.

## 남아 있는 신뢰 경계

1. **원본 웹사이트:** 로그인·게시·첨부와 사이트가 불러오는 스크립트·이미지·영상은 해당 서비스와 통신합니다. WebView 원본을 신뢰하는 것과 그 사이트가 손상된 상황까지 격리하는 것은 다릅니다.
2. **같은 웹 화면의 로컬 설정:** 메모·차단 규칙과 표시 결과는 원본 페이지의 JavaScript 실행 환경과 완전히 분리된 비밀 영역이 아닙니다. 앱 자체의 서버 송신 경로를 찾지 못했다는 것만으로 사이트 코드도 관찰할 수 없다고 주장하지 않습니다.
3. **FCM 발송 서버:** 기본 서버는 data-only 메시지와 고정된 문구를 사용합니다. Firebase SDK의 백그라운드 notification 처리까지 앱 콜백 하나로 모두 차단한다고 보장하지 않습니다. 서버 키·서버 운영자·Google 메시지 전달 경로도 신뢰 대상입니다.
4. **서드파티:** AndroidX, Firebase·Google Play 서비스, Android System WebView, Android OS와 모든 전이 의존성을 전부 디컴파일·동적 분석한 것은 아닙니다.
5. **개발·빌드 환경:** 서명·해시·재빌드 비교는 다른 목적의 검사입니다. 개발 PC·컴파일러·원격 서버의 운영 상태 전체를 증명하지 않습니다.

## 검토 방식과 공개 자료

공개한 생산 소스의 WebView 설정, 메시지 브리지, 외부 URL, 다운로드·파일 선택, 권한, 로컬 저장, 푸시 앱·서버의 자료 흐름을 읽고 관련 회귀 검사를 수행합니다. 실제 회원 쿠키·개인 사진·비밀키·실제 게시글을 검토 자료로 공개하지 않습니다. 공개 보고서는 재현에 필요한 일반 코드 위치, 파일 해시, 권한 이름, 범위와 판정으로 제한합니다.

개발자가 수행한 기능 검사 개수를 악성코드 검사 통과 수나 외부 감사 인증으로 표현하지 않습니다. CodeQL·lint·다중 백신·재현 빌드의 실행 여부와 한계는 각각 표시합니다.
