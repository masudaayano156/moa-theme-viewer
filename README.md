# 모아 — 커뮤니티 테마 뷰어

**[Android APK 다운로드 · 0.8.0 미리보기](https://github.com/masudaayano156/moa-theme-viewer/releases/download/v0.8.0/moa-0.8.0.apk)** · [릴리스와 체크섬](https://github.com/masudaayano156/moa-theme-viewer/releases/tag/v0.8.0)

Android 8.0 이상. 기존 0.3.2 이상은 삭제하지 않고 업데이트 설치할 수 있습니다. 미리보기 릴리스는 GitHub의 `Latest` 목록에 나타나지 않을 수 있으므로 위 다운로드 링크를 사용하세요.

연결한 웹 커뮤니티의 화면 배치를 선택한 스타일로 바꾸는 비공식 Android 앱입니다. 연결 서비스는 디시인사이드이며, 원본 글·댓글·작성 기능을 이용합니다. 디시인사이드 및 화면 구성에 참고한 서비스의 공식 앱이나 제휴 앱이 아닙니다.

## 기능

- 메일함(Gmail 참고)·X·인스타그램·엑셀·네이버 카페·E-book·매거진 스타일. 표시 이름을 바꿔도 기존 테마 설정과 저장한 페이지는 유지됩니다.
- 테마별로 별도의 목록 템플릿과 홈·탐색 구조를 사용합니다. 메일함의 라벨 서랍·작성 버튼, X의 피드, 인스타그램의 사진·캡션 배치, 엑셀의 수식 표시줄·셀 격자, 네이버 카페의 원형 즐겨찾기, E-book 책장과 목차를 제공합니다.
- 본문·댓글·작성 화면도 테마별 읽기·대화·작성 구조를 사용하며 원본 입력 요소는 유지합니다.
- 원본 폼과 링크를 유지하는 목록·본문·작성·댓글 화면 구성. 검색은 모바일 화면에서 열고 검색 결과의 게시판도 현재 테마를 이어서 적용합니다. 게시글 목록 맨 위에서 아래로 당겨 새로고침합니다.
- 엑셀 스타일은 600px 이상에서 분류·제목·작성자·댓글·조회 열을 나누며, 좁은 화면에서는 제목 위에 분류를 표시합니다.
- 사용자 계정의 즐겨찾기와 기기에 직접 저장한 페이지. 기본 커뮤니티 추천이나 특정 게시판 바로가기는 포함하지 않습니다.
- 테마별 표시 이름·마크, 글자 크기, 다크 모드, 창 크기 변경 대응. 화면 이름과 배치는 테마 표현이며 실제 기능은 연결한 커뮤니티에서 처리됩니다.
- 지원하지 않는 페이지는 원본 보기로 이용합니다. 원본과 테마 전환은 앱 메뉴에 있습니다.
- 선택형 FCM 푸시와 공개 글 댓글 수 확인. 앱에서 알림을 허용하면 기기 수신 확인과 서버 연결을 자동으로 처리합니다. 운영자에게 코드를 요청하거나 별도 서버에 가입하지 않아도 됩니다. 동의한 경우 앱에서 이후 작성한 글과 댓글을 자동 등록하며, 다른 사람 글에 남긴 내 댓글의 답글도 알립니다.
- 단어·공개 ID/IP·닉네임 차단, 이용자 메모, 글 보관함, 최근 본 글과 기록 끄기·삭제.
- 별도 WebView 계정 공간 최대 5개와 계정 전환. Android System WebView가 다중 프로필 기능을 지원해야 합니다. 비밀번호를 앱의 계정 목록에 저장하지 않습니다.
- 기본 테마색 또는 18가지 강조색, 넓은 창에서 목록·본문을 함께 보는 분할 모드. 접거나 창을 줄여도 작성 중인 페이지를 유지합니다.
- 사진 회전·가운데 자르기·크기 조절·JPEG/PNG 변환, 여러 사진으로 GIF 만들기, 문서 선택기를 통한 첨부·파일 저장.
- 게시글 이미지를 길게 눌러 저장·이미지 주소 복사·브라우저에서 이미지 열기를 선택합니다. 이미지 저장을 누르면 갤러리의 `Pictures/Moa`에 바로 저장하며 원본 이미지 바이트를 변환하지 않습니다. Android 8~9에서는 처음 저장할 때 저장 공간 권한이 필요하고, Android 10 이상에서는 전체 사진 접근 권한 없이 새 이미지를 추가합니다. 다른 종류의 첨부파일은 기존 파일 선택기를 사용합니다.
- 글·일반 댓글의 머리말/꼬리말을 전역 또는 게시판별로 저장하고 작성 화면에서 적용. 자동 등록하지 않습니다.

## 기능 범위

| 기능 | 현재 지원 범위 |
| --- | --- |
| 댓글 알림 | 같은 글의 전체 댓글 수와 여러 댓글의 답글을 묶어 확인합니다. 기준 간격은 2분 30초이며, 분 단위 예약으로 실제 확인은 보통 약 3분 간격입니다. 알림 배분·발송과 혼잡에 따른 지연은 별도입니다. 즉시 알림은 아닙니다. 앱에서 새로 작성한 글은 첫 확인 때 이미 달린 댓글도 알립니다. 직접 추가한 기존 글은 최초 확인 이후 증가부터 알리며, 글 전체의 총수가 그대로인 삭제·추가는 감지하지 못합니다. 개별 댓글의 답글은 고유 번호로 비교합니다. 자기 댓글도 증가에 포함됩니다. |
| 알림 등록 | 저장 개수 제한은 없습니다. 관리 화면에는 최근 20개만 표시합니다. 글과 댓글은 각각 작성 후 3일까지만 확인합니다. 목록 확인·다른 글 작성·새 댓글로는 기한을 늘리지 않습니다. 원하는 글은 직접 지금부터 3일 더 켤 수 있습니다. 무료 서버의 처리량은 함께 사용하며, 혼잡하거나 일일 작업 예산을 소진하면 확인과 알림이 지연됩니다. |
| 차단·이용자 메모 | 화면에 공개된 정보만 이용합니다. 원본 글이나 다른 이용자의 화면을 수정하지 않습니다. |
| 이미지 숨기기 | 본문·목록 이미지를 숨기며, 새로 로드하는 일반 글 화면의 확인된 DC 이미지 주소 요청도 차단합니다. 모든 이미지 서버의 요청 차단을 보장하지 않습니다. |
| GIF 터치 표시 | GIF로 식별된 이미지에 적용합니다. 프레임 정지가 아니며, 표시 전 이미 다운로드됐을 수 있습니다. |
| 글쓰기·임시저장 | 원본 텍스트 편집 기능과 로컬 자동 텍스트 초안 복원을 제공합니다. 첨부·서식·기존 글 수정·답글의 완전한 초안 복원은 지원하지 않습니다. |
| 자동 짤방 | 게시판의 원본 자동 짤방 설정으로 연결합니다. 적용·첨부는 원본 사이트 기능에 따릅니다. |
| 보이스 | 원본 모바일 웹이 공식앱으로 연결하므로 이 앱의 독립 녹음·업로드는 지원하지 않습니다. 보이스 리플 버튼과 공식앱 연결 메뉴는 숨깁니다. |

처음 실행하면 **글과 댓글의 새 답글 알림을 받을까요? → 알림 받기**로 한 번 동의합니다. 이미 알림 연결과 기기 권한을 허용한 이용자는 업데이트 후 자동 등록을 이어갑니다. Android가 알림 권한을 요청하면 함께 허용하세요. 앱이 기기 수신 확인과 서버 연결을 자동 처리하고 이후 이 앱에서 작성한 글과 댓글을 각각 작성 후 3일간 자동으로 등록합니다. 별도 자동 등록 스위치나 글마다 동의하는 과정은 없습니다. 통신 실패 시 등록할 주소를 기기 안에 보관해 다시 시도합니다. 거절한 경우 메뉴의 **댓글 알림 관리 → 푸시 연결 설정 → 댓글 알림 켜기**에서 시작할 수 있습니다.

이미 작성한 글·댓글 전체는 자동으로 소급 수집하지 않습니다. 이전 댓글도 현재 페이지에서 로그인한 본인 ID와 최근 3일의 작성 시각을 확인하면 자동으로 연결합니다. 댓글마다 알림을 따로 신청하지 않습니다. 이미 연결한 댓글은 기기에 기억해 중복 등록하지 않으며, 복원 시 과거 답글을 반복해서 알리지 않습니다. 원하는 기존 글은 열어서 **댓글 알림 관리 → 이 글도 알림 받기**로 추가할 수 있습니다. 휴대폰이 오프라인일 때 FCM은 댓글 알림을 최대 24시간 보관하지만, 실제 표시 시점은 네트워크·OS 설정에 영향을 받습니다. Android 설정에서 앱을 강제 종료한 경우에는 다시 실행해야 합니다.

처음 연결할 때는 앱을 열어 두고 완료 표시를 확인하세요. 연결 중 앱을 닫거나 통신이 끊겨도 저장된 상태로 재개하며, 운영자 승인 대신 **자동 연결 다시 시도**를 이용할 수 있습니다. 알림이 꺼져 있을 때는 등록을 시작하지 않고, 끄는 즉시 수신 확인 작업도 취소합니다. 기존에 연결한 기기는 같은 설치 정보와 구독을 유지합니다.

본문 내부의 확인된 Google·AdFit 광고 슬롯을 포함한 광고 영역과 게시판 아래의 실베·개념·디시미디어·디시이슈·외부 검색 영역은 테마 및 원본 보기에서 숨깁니다. 추천 카드가 나중에 불러와져도 하단 모듈을 계속 구분해 숨깁니다. 게시판 검색·페이지 이동·작성자가 넣은 콘텐츠·원본 입력 요소는 유지합니다. 이는 화면 정리 기능이며 모든 광고 네트워크 요청이나 추적을 차단하는 기능은 아닙니다. 원본 서비스가 화면 구조를 바꾸면 추가 대응이 필요할 수 있습니다.

미리보기를 위해 다른 게시글을 자동으로 수집하지 않으며, 현재 문서에 제공된 이미지가 없는 목록은 텍스트 피드로 표시합니다.

같은 글의 댓글이 같은 응답에 있으면 조회를 공유하고, 여러 페이지로 나뉘면 필요한 페이지를 추가로 확인합니다. 한 번에 처리할 작업을 나눠 과도한 사용을 막으므로, 등록 개수에 저장 제한이 없더라도 일정한 수신 속도를 보장하지 않습니다. 500개의 댓글 구독이 몇 개 글에 모인 경우와 500개의 서로 다른 글을 구독하는 경우는 사용량이 다릅니다. 무료 예산이나 많은 동시 알림으로 대기할 수 있습니다.

## 다운로드

비공식 미리보기 APK는 [GitHub Releases](https://github.com/masudaayano156/moa-theme-viewer/releases)에서 제공합니다. Android 8.0 이상이 필요합니다. 각 릴리스의 설치 파일과 SHA-256을 확인하세요. 아직 실제 기기·계정의 모든 동작을 검증한 정식 배포판은 아닙니다.

0.3.2부터 전용 배포 키와 디버깅을 끈 릴리스 빌드를 사용합니다. 기존 0.3.1 이하 개발용 APK와 서명이 달라 그 위에 덮어 설치할 수 없습니다. 기존 개발판을 삭제하면 기기 안의 로그인·설정·저장 페이지·초안이 지워지므로 필요한 내용은 먼저 보관하세요. 서버에 등록한 글과 계정 즐겨찾기는 영향을 받지 않습니다.

## 빌드

JDK 17과 Android SDK 35가 필요합니다. Gradle 8.9 Wrapper를 포함하며 Android Gradle Plugin 8.7.3을 사용합니다. SDK 라이선스는 개발자가 직접 확인하고 동의해야 합니다.

1. Android Studio에서 이 폴더를 엽니다.
2. SDK Platform 35 및 필요한 빌드 도구를 설치합니다.
3. 로컬 SDK 위치는 Android Studio가 설정하게 하거나 `ANDROID_HOME` 환경 변수로 지정합니다. `local.properties`와 로컬 경로는 저장소에 포함하지 않습니다.
4. 다음 명령으로 개발용 APK를 만듭니다.

Windows PowerShell:

```powershell
.\gradlew.bat assembleDebug
```

macOS / Linux:

```sh
sh ./gradlew assembleDebug
```

정적 분석은 `lint` 태스크로 실행할 수 있습니다. `assembleRelease`는 별도 릴리스 서명을 설정하지 않은 상태의 산출물을 만듭니다. 서명 키·비밀번호·인증 토큰은 저장소 밖에서 관리해야 합니다.

푸시는 기본적으로 꺼져 있습니다. 개인 Firebase Android 설정을 사용하려면 저장소 밖의 `google-services.json` 경로를 `-PmoaFirebaseConfig`로, 배포한 정확한 HTTPS `workers.dev` 주소를 `-PmoaPushEndpoint`로 전달합니다. 설정이 없는 소스 빌드는 기존 커뮤니티 기능을 사용할 수 있고 푸시 설정만 비활성화됩니다. 앱 설정 식별자는 연결된 APK에 포함되지만 서버 개인키는 절대 포함하지 않습니다.

기기 연결 서버의 일반 템플릿과 API 설명은 [push-worker](push-worker/README.md)에 있습니다. 실제 Cloudflare 계정·데이터베이스 ID·Firebase 프로젝트 값은 비공개 배포 설정에 두며, 서버의 FCM 개인키와 관리자 비밀값은 Worker Secret으로 보관합니다. 서버 키를 앱 설정 파일로 전달하면 빌드가 거부됩니다.

앱 패키지는 `app.moa.client`이며 최소 Android 8.0(API 26), compileSdk/targetSdk 35입니다. 현재 버전은 개발 시제품입니다. 실제 기기·계정·외부 서비스 동작과 스토어 배포 허용 범위는 별도 확인이 필요합니다.

## 저장소 범위와 개인정보

소스 이력에는 앱 소스·독립 디자인 자산·빌드 설정·필요한 제3자 고지만 포함합니다. 실제 게시글이나 회원 정보, 원본 사이트 HTML/CSS 사본, 테스트 코드·자료, 개발 기록·스크린샷·로그, 계정 데이터, 서명 키는 포함하지 않습니다. 검토한 배포 APK와 체크섬은 소스 이력과 분리하여 Releases에만 제공합니다.

`.gitignore`는 검토한 파일만 허용하는 방식입니다. 새 파일을 추가할 때는 공개해도 되는 내용인지 확인한 뒤 목록에 반영해야 합니다. 빌드 폴더나 개인 설정을 강제로 추가하지 마세요.

앱 사용 중 로그인 쿠키와 웹 저장소는 Android WebView가 관리합니다. 테마 설정·차단·메모·보관함·방문 기록·계정 공간 이름·일부 텍스트 초안은 기기 내부에 저장되며, 저장소에는 이러한 사용자 데이터가 들어 있지 않습니다. 방문 기록은 설정에서 끄거나 지울 수 있습니다. 계정 즐겨찾기 목록은 별도 파일로 저장하지 않습니다.

앱은 인터넷·카메라·마이크·알림 권한을 선언하며, FCM SDK는 푸시 수신에 필요한 네트워크 상태·기기 깨우기 등의 일반 권한을 추가합니다. 재부팅 후 대기 중인 알림 등록 작업을 재개하기 위한 일반 권한도 선언합니다. 카메라·마이크·알림은 해당 기능 사용 시 Android의 사용자 허용을 따릅니다. Android 8~9에서는 새 이미지를 갤러리에 저장하기 위한 저장 공간 권한이 필요하며, Android 10 이상에는 적용하지 않습니다. 앱은 기기의 기존 사진을 탐색하거나 업로드하지 않습니다. 위치·SMS·연락처 권한은 선언하지 않습니다. 사진 파일 선택과 웹 카메라·마이크 사용은 별개 기능입니다.

알림을 켜면 Google FCM에 기기별 식별자가 등록됩니다. 자동 수신 확인 후 Cloudflare 서버에 푸시 토큰과 임의의 설치 식별자가 저장됩니다. 수신 확인 값은 앱이 시작한 요청과 일치할 때만 사용하고 짧게 보관하며, 서버에는 확인 값과 설치 비밀값의 해시만 저장합니다. 앱 전체가 공유하는 관리자 비밀값은 APK에 넣지 않습니다. 글 알림 등록 시 **알림을 허용한 뒤 앱에서 작성·직접 추가하거나 현재 화면에서 본인 소유로 확인해 복원한 최근 댓글의 공개 글·댓글 URL·댓글 번호·댓글 수·최신 답글 번호·확인 시각**도 저장합니다. 서버는 로그인하지 않고 공개 페이지를 읽으며 본문·작성자·제목을 저장하지 않습니다. 같은 글의 대상별 번호·개수·최신 답글 번호를 잠시 공유해 처리하고 처리 후 임시 묶음을 지웁니다. 변화가 없는 댓글별 기록은 반복 갱신하지 않습니다. 화면의 첫 페이지에 없는 댓글은 원본 모바일 웹의 익명 댓글 조회 기능으로 찾습니다. 이때 사이트가 발급한 임시 익명 세션만 같은 사이트의 조회에 사용하고 저장하지 않으며 앱의 로그인 쿠키는 사용하지 않습니다. 디시 비밀번호·로그인 쿠키는 이 서버로 보내지 않습니다. 알림 내용은 기기에서 테마에 맞는 정해진 문구로 만들고 잠금화면에는 내용을 숨깁니다. 해제 시 기기의 알림 표시를 중단하고 토큰 폐기·서버 삭제를 요청하며, 통신 실패에 대비한 정리 정보는 앱 내부에 남겨 다음 연결 때 삭제를 재시도합니다.

## 라이선스와 서비스 권리

프로젝트 자체 코드에 적용할 공개 라이선스는 아직 선택하지 않았습니다. 따라서 현재 소스 공개가 자유로운 수정·재배포 라이선스 부여를 의미하지는 않습니다. 포함된 Gradle Wrapper와 빌드 의존성에는 각자의 라이선스가 적용되며, [제3자 고지](THIRD_PARTY_NOTICES.md)에 구분했습니다.

디시인사이드 콘텐츠·상표·서비스의 권리는 해당 권리자에게 있습니다. 이 저장소는 타인의 콘텐츠 이용권을 부여하지 않습니다. 테마 변경·광고 숨김이나 GitHub 배포가 사이트 운영자의 허락을 의미하지는 않습니다. 서비스 이용 조건은 해당 운영자의 안내를 확인해야 합니다.

- [Google Play 개발자 정책](https://support.google.com/googleplay/android-developer/answer/18258653?hl=en)
