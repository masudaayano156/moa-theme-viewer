# 모아 — 커뮤니티 테마 뷰어

연결한 웹 커뮤니티의 화면 배치를 선택한 스타일로 바꾸는 비공식 Android 앱입니다. 연결 서비스는 디시인사이드이며, 원본 콘텐츠와 광고를 유지합니다. 디시인사이드 및 화면 구성에 참고한 서비스의 공식 앱이나 제휴 앱이 아닙니다.

## 기능

- 메일함·포스트·포토그램·카페·스프레드 시트·E-book·매거진 스타일.
- 테마별로 별도의 목록 템플릿과 홈·탐색 구조를 사용합니다. 메일함의 주제함 서랍, 포토그램의 피드/모아보기, 시트의 열 머리글·가로 스크롤, E-book 책장과 목차를 제공합니다.
- 본문·댓글·작성 화면도 테마별 읽기·대화·작성 구조를 사용하며 원본 입력 요소는 유지합니다.
- 원본 폼과 링크를 유지하는 목록·본문·작성·댓글 화면 구성.
- 사용자 계정의 즐겨찾기와 기기에 직접 저장한 페이지. 기본 커뮤니티 추천이나 특정 게시판 바로가기는 포함하지 않습니다.
- 테마별 독립 이름·심벌, 글자 크기, 다크 모드, 창 크기 변경 대응.
- 지원하지 않는 페이지는 원본 보기로 이용합니다. 원본과 테마 전환은 앱 메뉴에 있습니다.

광고 영역과 AD 표시는 유지합니다. 메뉴의 ‘닫을 수 있는 광고 닫기’는 원본이 제공하는 고정 광고 닫기 버튼을 사용자가 요청했을 때 실행합니다. 원본에 닫기 기능이 없는 광고를 숨기거나 자동으로 광고를 차단하지 않습니다. 미리보기를 위해 다른 게시글을 자동으로 수집하지 않으며, 현재 문서에 제공된 이미지가 없는 목록은 텍스트 피드로 표시합니다.

## 빌드

JDK 17과 Android SDK 35가 필요합니다. Gradle 8.9 Wrapper를 포함하며 Android Gradle Plugin 8.7.3을 사용합니다. SDK 라이선스는 개발자가 직접 확인하고 동의해야 합니다.

1. Android Studio에서 이 폴더를 엽니다.
2. SDK Platform 35 및 필요한 빌드 도구를 설치합니다.
3. 로컬 SDK 위치는 Android Studio가 설정하게 하거나 `ANDROID_HOME` 환경 변수로 지정합니다. `local.properties`와 로컬 경로는 저장소에 포함하지 않습니다.
4. 다음 명령으로 개발용 APK를 만듭니다.

Windows PowerShell:

```powershell
.\gradlew.bat assembleDebug
```

macOS / Linux:

```sh
sh ./gradlew assembleDebug
```

정적 분석은 `lint` 태스크로 실행할 수 있습니다. `assembleRelease`는 별도 릴리스 서명을 설정하지 않은 상태의 산출물을 만듭니다. 서명 키·비밀번호·인증 토큰은 저장소 밖에서 관리해야 합니다.

앱 패키지는 `app.moa.client`이며 최소 Android 8.0(API 26), compileSdk/targetSdk 35입니다. 현재 버전은 개발 시제품입니다. 실제 기기·계정·외부 서비스 동작과 스토어 배포 허용 범위는 별도 확인이 필요합니다.

## 저장소 범위와 개인정보

이 저장소에는 앱 소스·독립 디자인 자산·빌드 설정·필요한 제3자 고지만 포함합니다. 실제 게시글이나 회원 정보, 원본 사이트 HTML/CSS 사본, 테스트 코드·자료, 개발 기록·스크린샷·로그, 설치 파일, 계정 데이터, 서명 키는 포함하지 않습니다.

`.gitignore`는 검토한 파일만 허용하는 방식입니다. 새 파일을 추가할 때는 공개해도 되는 내용인지 확인한 뒤 목록에 반영해야 합니다. 빌드 폴더나 개인 설정을 강제로 추가하지 마세요.

앱 사용 중 로그인 쿠키와 웹 저장소는 Android WebView가 관리합니다. 테마 설정과 사용자가 저장한 페이지·일부 텍스트 초안은 기기 내부에 저장되며, 저장소에는 이러한 사용자 데이터가 들어 있지 않습니다. 계정 즐겨찾기 목록은 별도 파일로 저장하지 않습니다.

## 라이선스와 서비스 권리

프로젝트 자체 코드에 적용할 공개 라이선스는 아직 선택하지 않았습니다. 따라서 현재 소스 공개가 자유로운 수정·재배포 라이선스 부여를 의미하지는 않습니다. 포함된 Gradle Wrapper와 빌드 의존성에는 각자의 라이선스가 적용되며, [제3자 고지](THIRD_PARTY_NOTICES.md)에 구분했습니다.

디시인사이드 콘텐츠·상표·서비스의 권리는 해당 권리자에게 있습니다. 이 저장소는 타인의 콘텐츠 이용권을 부여하지 않습니다. 테마 변경과 광고 유지는 사이트 운영자의 허락이나 스토어 심사를 대신하지 않습니다. 공개 앱 배포 전 서비스 운영자의 허용 범위와 적용 정책을 확인해야 합니다.
