## 기능

- 메일함(Gmail 참고)·X·인스타그램·엑셀·네이버 카페·E-book·매거진 스타일. 표시 이름을 바꿔도 기존 테마 설정과 저장한 페이지는 유지됩니다.
- 테마별로 별도의 목록 템플릿과 홈·탐색 구조를 사용합니다. 메일함의 라벨 서랍·작성 버튼, X의 피드, 인스타그램의 사진·캡션 배치, 엑셀의 수식 표시줄·셀 격자, 네이버 카페의 원형 즐겨찾기, E-book 책장과 목차를 제공합니다.
- 본문·댓글·작성 화면도 테마별 읽기·대화·작성 구조를 사용하며 원본 입력 요소는 유지합니다.
- 원본 폼과 링크를 유지하는 목록·본문·작성·댓글 화면 구성. 검색은 모바일 화면에서 열고 검색 결과의 게시판도 현재 테마를 이어서 적용합니다. 게시글 목록과 본문 맨 위에서 아래로 당겨 새로고침합니다. 작성 중인 댓글·답글이 있으면 이동 확인을 거칩니다.
- 엑셀 스타일은 600px 이상에서 분류·제목·작성자·댓글·조회 열을 나누며, 좁은 화면에서는 제목 위에 분류를 표시합니다.
- 사용자 계정의 즐겨찾기와 기기에 직접 저장한 페이지. 기본 커뮤니티 추천이나 특정 게시판 바로가기는 포함하지 않습니다.
- 테마별 표시 이름·마크, 글자 크기, 다크 모드, 창 크기 변경 대응. 화면 이름과 배치는 테마 표현이며 실제 기능은 연결한 커뮤니티에서 처리됩니다.
- 지원하지 않는 페이지는 원본 보기로 이용합니다. 원본과 테마 전환은 앱 메뉴에 있습니다.
- 단어·공개 ID/IP·닉네임 차단, 이용자 메모, 글 보관함, 최근 본 글과 기록 끄기·삭제.
- 별도 WebView 계정 공간 최대 5개와 계정 전환. Android System WebView가 다중 프로필 기능을 지원해야 합니다. 비밀번호를 앱의 계정 목록에 저장하지 않습니다.
- 기본 테마색 또는 18가지 강조색, 넓은 창에서 목록·본문을 함께 보는 분할 모드. 접거나 창을 줄여도 작성 중인 페이지를 유지합니다.
- 사진 회전·가운데 자르기·크기 조절·JPEG/PNG 변환, 여러 사진으로 GIF 만들기, 문서 선택기를 통한 첨부·파일 저장.
- 게시글 이미지를 길게 눌러 저장·이미지 주소 복사·브라우저에서 이미지 열기를 선택합니다. 이미지 저장을 누르면 갤러리의 `Pictures/Moa`에 바로 저장하며 원본 이미지 바이트를 변환하지 않습니다. Android 8~9에서는 처음 저장할 때 저장 공간 권한이 필요하고, Android 10 이상에서는 전체 사진 접근 권한 없이 새 이미지를 추가합니다. 다른 종류의 첨부파일은 기존 파일 선택기를 사용합니다.
- 글·일반 댓글의 머리말/꼬리말을 전역 또는 게시판별로 저장하고 작성 화면에서 적용. 자동 등록하지 않습니다.

- 앱을 사용하는 동안 댓글·답글 알림 팝업과 상단 알림함을 제공합니다. 기존 모바일 웹 기록에서 최근 20개까지 가져오고 앱이 관찰한 최근 100개를 계정별로 보관합니다. 읽지 않은 배지·모두 읽음·개별/전체 삭제·댓글 이동을 지원합니다. 별도 푸시 서버나 글별 등록은 없습니다.

## 앱 안 알림

환경 설정 또는 메뉴의 **앱 안 알림**에서 켜거나 끌 수 있습니다. 기본값은 켜짐입니다. Android 시스템 알림 권한은 요청하지 않습니다. 팝업과 상단 알림함에서 해당 글·댓글로 이동합니다. 알림함의 읽음·삭제 상태는 이 앱의 계정별 기록에만 적용하며 원본 웹 기록을 직접 변경하지 않습니다. 알림함을 닫으면 입력하던 페이지를 유지합니다. 실베·홍보 알림은 댓글 팝업으로 바꾸지 않습니다.

알림은 원본 디시 웹의 알림 응답·표시를 이용합니다. 모바일 웹의 기존 알림 함수를 사용하며, 현재 문서의 원본 알림이 시작된 경우 앱이 활성화된 동안 하나의 약 90초 주기를 유지합니다. 계정·원본 알림 설정과 사이트 동작의 영향을 받습니다. 앱이 백그라운드로 가거나 홈만 보거나 알림을 끄면 앱의 알림 주기를 멈춥니다. 분할 보기에서는 현재 선택한 한쪽 문서만 팝업을 표시합니다.

글·댓글을 운영자 서버에 자동 등록하거나 3일간 추적하지 않습니다. 디시 로그인 정보도 운영자 서버로 보내지 않습니다. 종료된 푸시 서버의 기존 기록은 운영자의 선택에 따라 보존된 상태이며 더 이상 조회·발송에 사용하지 않습니다. 이전 FCM으로 이미 전달된 알림을 회수하는 기능은 없습니다.

확인된 본문 광고와 게시판 하단의 실베·외부 추천 영역을 숨깁니다. 게시판 검색·페이지 이동·작성자·본문 이미지·댓글·입력 요소는 유지합니다. 화면 정리 기능이며 모든 광고 네트워크 요청을 차단한다는 뜻은 아닙니다.

## 빌드

JDK 17과 Android SDK 35가 필요합니다. Gradle 8.9 Wrapper를 포함하며 Android Gradle Plugin 8.7.3을 사용합니다. SDK 라이선스는 개발자가 직접 확인하고 동의해야 합니다.

1. Android Studio에서 이 폴더를 엽니다.
2. SDK Platform 35 및 필요한 빌드 도구를 설치합니다.
3. 로컬 SDK 위치는 Android Studio가 설정하게 하거나 `ANDROID_HOME` 환경 변수로 지정합니다. `local.properties`와 로컬 경로는 저장소에 포함하지 않습니다.
4. 다음 명령으로 개발용 APK를 만듭니다.

Windows PowerShell:

```powershell
.\gradlew.bat assembleDebug
```

macOS / Linux:

```sh
sh ./gradlew assembleDebug
```

정적 분석은 `lint` 태스크로 실행할 수 있습니다. `assembleRelease`는 별도 릴리스 서명을 설정하지 않은 상태의 산출물을 만듭니다. 서명 키·비밀번호·인증 토큰은 저장소 밖에서 관리해야 합니다.

Firebase 설정이나 푸시 서버 주소 없이 빌드합니다. 개인키·서명 설정·계정 자료는 저장소 밖에서 관리합니다. 앱 패키지는 `app.moa.client`이며 최소 Android 8.0(API 26), compileSdk/targetSdk 35입니다.

소스에는 앱 코드·디자인 자산·빌드 설정·제3자 고지와 사용자 자료가 없는 검증 보고서만 포함합니다. 사용자 로그인 정보·원본 게시글·사진·테스트 자료·스크린샷·로그·키는 공개하지 않습니다. APK는 소스 이력과 분리해 Releases에서 제공합니다.
