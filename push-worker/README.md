# 종료한 모아 푸시 중계

0.9.0부터 앱은 이 서버나 Firebase를 사용하지 않습니다. 알림은 앱이 활성화된 동안 디시 웹에서 받아 테마 팝업으로 표시합니다.

이 폴더는 기존 APK에 종료 상태를 알리는 작은 Worker만 남깁니다. `/health`는 `status: retired`, 그 밖의 경로는 HTTP 410 `push_retired`를 반환합니다. 데이터베이스·외부 API·FCM·예약 조회·발송 기능이 없습니다. 공개 설정의 Cron 목록도 비어 있습니다.

이전 구현은 소스 이력에만 남습니다. 실제 운영 데이터베이스의 기존 기록은 운영자 선택으로 보존하며 서버에 연결하지 않습니다. 실제 비밀값·계정·DB 식별자를 이 폴더에 추가하지 마세요.
